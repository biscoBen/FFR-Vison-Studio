# Crystal Fina optical review material

`refraction.png` is a generated, character-free sapphire light/facet field used only by
`scripts/render_crystal_fina_refraction.py` for the local lighter/denser comparison exports.
It rotates with the original full 3D crystal. No new character or face painting is projected
onto the crystal. The original character/background layers live in `../crystal_fina_layers`.

Both variants keep the original scene motion, eye-region animation and soundtrack. The user
selected the existing lighter MP4 for the runtime test. Its unchanged preview and a game-format
copy are now packaged; the alternative artwork remains a separate local review.
