CRYSTAL FINA - FULL GAME RUNTIME DIAGNOSTICS

1. Extract this ZIP into a folder outside the game.
2. Open the full game with your installed mod. Enter a battle with Crystal Fina;
   try her regular attack and resonance if possible. You can leave the game open.
3. Double-click Collect Fina Runtime Diagnostics.cmd.
4. Check that the displayed game folder is FINAL FANTASY RESONANCE, without DEMO.
   Press Enter to accept it, or paste your full game folder.
5. Send back the Fina-Runtime-Diagnostics-....zip it creates in Downloads\FFR Mod.

This helper finds Studio on the desktop or in common download locations and reads
the full game's installed Fina scripts, loader log and Studio runtime records.
If it asks for Studio, select the Sephira-Studio-Test folder you actually use.
It does not change the game or collect saves, credentials, or game assets.
No Studio update or reinstall is required to run this helper.
