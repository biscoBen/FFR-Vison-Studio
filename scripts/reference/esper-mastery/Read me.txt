Esper mastery diagnostics for Studio 1.2.107

1. Extract this entire ZIP. Close Resonance. Run Install Esper Diagnostics.cmd.
   It finds the full game at D:\Steam\steamapps\common\FINAL FANTASY RESONANCE
   first, and prompts so you can confirm or enter another location.
   It adds its own read-only observer to the existing UE4SS installation.
   No Studio rebuild or mod reinstall is required.

2. Start Resonance. Equip Eiko's learned esper MR rewards ON PARTY FINA
   (or equip Spirit of Eiko on her). Learning them or equipping Eiko alone is
   not enough: these are equipable rewards. Use Fina's native summon command.
   Spend some MP first so MP recovery has room to show up.

3. In battle, press F8 before summoning, again with the esper present, then
   after its final special. Let it complete its full rotation. If possible,
   repeat in another battle with the same esper and the rewards unequipped.
   F8 only bookmarks/snapshots; it does not advance turns. F9 stops tracing.

4. BEFORE restarting Resonance, run Collect Esper Diagnostics.cmd.
   The game can remain open. Send the resulting Esper-Mastery-Diagnostics ZIP
   in Downloads\FFR Mod. Tell us which esper/rewards you tested and whether
   the equipped run or the unequipped run came first.

5. Close the game and run Disable Esper Diagnostics.cmd after testing.

What is recorded:
- Whether the installed Studio runtime contains/enables esper mastery.
- Existing [FFR Esper] activation/errors, plus separate [FFR Esper Trace] data.
- Fina's actual continuous effect IDs and the four mastery marker IDs.
- Battle unit IDs, allegiance, AI class, owner links, HP/MP, action counts,
  selected skills and sampled active skill jobs. Other unit IDs are retained
  so a different esper variant can be identified instead of silently ignored.
- Installed Studio runtime scripts/config, observer scripts and loader hash.

The observer does not hook or change skills, stats, effects, summons, saves,
loadouts, battle timing, remaining-action getters or native think getters.
Short events can fall between 100 ms samples; absence alone is not proof that
an effect failed. Reflection fields that cannot be read are reported explicitly.
Tracing stops after 15 minutes of battle samples or 10,000 lines.

PowerShell options (no hard-coded drive required):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "Esper Mastery Diagnostics.ps1" -Action Install -GamePath "D:\Steam\steamapps\common\FINAL FANTASY RESONANCE" -NoPrompt
Use -Action Collect or -Action Disable with the same -GamePath as needed.
