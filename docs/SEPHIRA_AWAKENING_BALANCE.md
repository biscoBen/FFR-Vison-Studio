# Sephira awakening bonus balance

Revision 7 restores the missing awakening bonus layer while preserving every revision 6 MR reward, all 131 distinct excluded-original passives, active skills, permanent stats and acquisition settings. Each complete kit has the same number of passives as its native stat/Resonance counterpart. This is a per-vision comparison: paired challenge rewards do not divide one original kit between two visions.

Choices follow each unit’s role. Native effects and AP equip costs are unchanged, so these are learned options rather than free permanent bonuses. Combined passive equip-cost totals stay within 20% of the counterpart; this is a useful budget check, not a claim that AP costs measure combat strength exactly. No second percentage tier of the same main stat is added to a kit. The existing active skill, stat and Resonance budgets remain; playing the game is still needed to assess difficult combinations.

The earlier rule reserving passives for MR is extended here at the user’s request: supplementary passives are awakening bonuses and stay out of battle commands. MR still has one reward per rank, with three at MR 9. Kept original visions’ MR rewards are still excluded.

For saved collection entries, use **Apply MR and acquisition update**, then rebuild/install. It backs up the roster and adds only missing awakening choices. Existing MR edits, active skills, artwork, identities and locations are retained. A full edited awakening kit reports a capacity error before saving rather than deleting a skill. New/restored presets include the bonuses.

Validation: all 30 awakening/MR kits serialize and read back through the native game tool with valid passive identities and names. The complete Python/Flutter suites and analyzer pass. This establishes data integrity and migration behavior; final gameplay balance still requires playtesting.
